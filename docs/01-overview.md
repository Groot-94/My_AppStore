# 01. 프로젝트 개요

## 목적

애플 **App Store** iOS 앱의 UI/UX와 주요 기능을 실제에 가깝게 재현하는 클론 앱. 학습·포트폴리오 목적이며, 실데이터는 애플의 공개 iTunes API를 사용한다.

## 목표

- 실제 App Store와 유사한 **5개 탭 구조**(Today, Games, Apps, Arcade, Search) 재현
- **실제 앱 데이터**(아이콘, 스크린샷, 설명, 평점, 카테고리)로 화면 구성
- UIKit으로 먼저 완성하고, **동일 로직을 재사용**해 SwiftUI 버전을 추가
- 확장 가능한 **모듈형 클린 아키텍처**로 구성

## 범위 (In Scope)

- 5개 탭 화면 및 탭 간 이동
- 앱 상세 화면(스크린샷, 설명, 평점, 정보, "받기" 버튼 UI)
- 검색(자동완성 없이 검색 실행 기준) 및 결과 목록
- 인기 차트(무료/유료) 표시
- 이미지 비동기 로딩/캐싱

## 범위 밖 (Out of Scope)

- 실제 앱 다운로드/설치, 결제(버튼은 UI만)
- Apple ID 로그인/계정, 구매 내역
- 서버/백엔드 자체 구축(데이터는 iTunes API에 의존)
- 푸시 알림, 위젯
- 다운로드 진행률 등 시스템 연동 동작

## 데이터 출처

애플 공개 API(인증 불필요). 상세는 [04-data-api](04-data-api.md).

- **iTunes Search API** — 키워드 검색
- **iTunes Lookup API** — ID로 앱 상세 조회
- **Apple Marketing RSS** — 국가별 인기 차트(무료/유료)

> 한계: "Today" 탭의 에디터 큐레이션(스토리/특집 카피)은 API에 없다. 해당 부분은 앱 내에 소량의 정적 큐레이션 데이터를 두고, 실제 앱 정보는 Lookup으로 채운다.

## 대상 환경

- iOS 17.0+
- iPhone 우선(가로/아이패드는 범위 밖)
- 다크/라이트 모드 지원
- 한국(`kr`) 스토어 기준, 국가 코드는 설정 가능하게 상수화
